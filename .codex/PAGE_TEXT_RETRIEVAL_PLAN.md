  -  # Slice 1 — Page-text content outcome contract                                                                                                                                                                                    
                                                                                                                                                                                                                                    
  ## Summary                                                                                                                                                                                                                        
                                                                                                                                                                                                                                    
  Add a private, deterministic classifier in dataforseo.py. It determines whether a validated content_parsing/live response is usable, retryable for rendering/pool recovery, or terminal. It makes no requests; retry behavior     
  belongs to later slices.                                                                                                                                                                                                          
                                                                                                                                                                                                                                    
  ## Contract                                                                                                                                                                                                                       
                                                                                                                                                                                                                                    
  Classify each response, in this precedence order:                                                                                                                                                                                 
                                                                                                                                                                                                                                    
  1. timeout — any task has status_code == 50402 or crawl_status == "timeout" (case-insensitive).                                                                                                                                   
  2. pool_related — a task status_message or result crawl_status contains: access denied, forbidden, location, geo, or unreachable.                                                                                                 
  3. javascript_disabled — structured page content or Markdown contains javascript is disabled (case-insensitive).                                                                                                                  
  4. usable — parsed_page_text_details() yields non-blank text or raw_html.                                                                                                                                                         
  5. empty — a 20000 / Ok response has null/empty results, items_count == 0, no items, or items whose page content and Markdown yield neither text nor HTML.                                                                        
  6. provider_failure — any remaining non-success task state.                                                                                                                                                                       
                                                                                                                                                                                                                                    
  20000 / Ok is transport success only; it never implies usable.                                                                                                                                                                    
                                                                                                                                                                                                                                    
  ## Implementation                                                                                                                                                                                                                 
                                                                                                                                                                                                                                    
  - Add private string constants and classify_page_text_response(response) -> str; do not add a public type, CLI option, or schema field.                                                                                           
  - Read task status_message and result crawl_status for provider failures; inspect only page_content and page_as_markdown for the JavaScript-disabled marker, not arbitrary raw HTML.                                              
  - Keep existing response-schema validation. Call the classifier after validation and before any page-text response is accepted by retrieval/resume code in later slices.                                                          
  - Preserve parsed_page_text_details() as the sole usable-content extractor, so normalization and live acquisition agree on what counts as content.

          # Slice 2 — Staged live page-text retrieval                                                                                                                                                                                       
                                                                                                                                                                                                                                    
  ## Summary                                                                                                                                                                                                                        
                                                                                                                                                                                                                                    
  Execution lane: CLI. Confidence: HIGH.                                                                                                                                                                                            
                                                                                                                                                                                                                                    
  Implement a shared live retrieval sequence for both fresh runs and stored-run missing-page resumes:                                                                                                                               
                                                                                                                                                                                                                                    
  1. Baseline: JavaScript and browser rendering off.                                                                                                                                                                                
  2. JavaScript/XHR: JavaScript on, browser rendering off.                                                                                                                                                                          
  3. Browser fallback: JavaScript and browser rendering on.                                                                                                                                                                         
                                                                                                                                                                                                                                    
  Return immediately on usable; retain only the winning response (or the final attempted response) so normalization and scoring inputs remain unchanged.

  - Advance only on empty or javascript_disabled; keep timeout, pool_related, and provider_failure terminal for Slice 3 recovery.                                                                                                   
  - Keep CLI flags, raw-response schema, normalization, and scoring eligibility unchanged.
